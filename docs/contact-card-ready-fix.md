# Contact 工牌白牌闪现修复（2026-11-21）

根因：DOM 占位工牌在生成图未就绪时就显示浅色底板；WebGL 在 resize 的首次渲染就回调 onReady，而正反面图片尚未完成加载，过早撤掉占位内容。

修改：
- 等完整图片触发 onLoad 后才显示静态占位工牌；此前只显示简短准备提示。
- 渲染模块与生成图片并行加载，待正反面内容可用后挂载动画。
- WebGL 画布初始隐藏；图片加载成功、贴图绘制完并完成第一次实际渲染后才显示画布及通知 ready。
- 贴图失败使用原有完整图片降级；动画从贴图准备好后开始，保留加载期间排队的背面显示请求。

验证：构建通过；390×740 视口、头像/二维码人为延迟 3 秒、动画模块延迟 2 秒时，记录约 700 帧，空白占位工牌可见帧为 0；流程为准备提示 → 已解码完整静态工牌 → 有贴图的动画。普通翻面通过，加载期间提前请求联系方式仍显示背面。此为本地延迟测试，不代表真实手机加载耗时。
