# 手机项目堆叠间距修正（2026-11-21）

恢复原有三张滚动堆叠卡片，撤销上一版点选切换卡片组。

手机三张卡片等高，两段间距统一为 24svh。移除每张卡片的 margin-bottom，由同一 flex gap 控制，避免叠加与差异。堆叠顶部偏移维持 16 / 48 / 80px。

末尾添加实际占位元素（伪元素），让第三张卡片抵达 80px 后三层都能停留；仅增加 padding-bottom 不会延长 flex 内容区的 sticky 约束边界，会导致第二、第三层提前一起释放，造成间距塌缩。

不足 600px 高的手机视口使用普通顺序卡片，避免横屏时裁切内容。桌面原有堆叠不变。

用户要求图片加载部分暂不调整；本轮图片导出、加载机制和画廊改动均已撤回，仅发布堆叠修正。
